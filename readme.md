# # Conversor de Archivos CSV a JSON
https://chriss-ag.github.io/MiniProyectoArchivos/

## Mini Proyecto Archivos

Aplicación web desarrollada para realizar la conversión de archivos de formato CSV a formato JSON.

## Funcionalidad

La aplicación permite:

1. Seleccionar un archivo CSV desde el computador.
2. Leer el contenido del archivo.
3. Procesar los encabezados y registros.
4. Convertir la información a una estructura JSON.
5. Mostrar el resultado en pantalla.
6. Descargar el resultado como un archivo `.json`.

## Formato de entrada

CSV

## Formato de entrada

JSON
